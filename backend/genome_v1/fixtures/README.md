# Genome v1 protocol metadata fixtures

Every file in this directory is synthetic, inert recorded metadata. It is a
schema/import fixture only: it does not represent an external execution,
interoperability result, safety assessment, deployment, or live trace.

The OTel, A2A, and MCP fixtures preserve only the bounded metadata shape needed
for catalog/import tests. They deliberately contain no prompts, credentials,
authorization headers, tool outputs, or executable configuration.
