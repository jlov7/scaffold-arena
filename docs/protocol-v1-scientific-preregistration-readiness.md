# Protocol-v1 scientific preregistration readiness

This repository contains offline preparation for a flagship comparative study and a no-retuning transfer study. It is not a preregistration publication, a live run, or a result.

The dedicated declarative StudyPacks are [`flagship-prereg-v1`](../study_packs/flagship-prereg-v1/study-pack.json) and [`transfer-prereg-v1`](../study_packs/transfer-prereg-v1/study-pack.json). Their custody manifests bind a draft and placeholder fixture identities, not actual frozen policy content. `scripts/validate-scientific-preregistration.py` verifies canonical file hashes, StudyPack parsing, frozen matrix completeness, fixture/live separation, and the unpublished preregistration HOLD.

Each draft contract has fields for model, harness, evaluator, local runtime identity, sampling, budgets, stopping rules, exclusions, severe-failure policy, analysis, and multiplicity digests. The checked-in repeated-character digests are explicit fixture sentinels, not bindings to real policy content. Fixture planning may use them; confirmatory admission rejects them with `HOLD_PLACEHOLDER_FROZEN_BINDINGS`, even if public publication fields are toggled. Local runtimes are admitted only as named native Ollama or LM Studio identities. The generic OpenAI-compatible adapter remains protocol-only and is not an admission path. Local runtime policy is `zero_paid_cost_local_energy_unknown`: no price is invented, and energy is not represented as zero.

The transfer contract requires a frozen selection receipt, equality of selection and transfer configuration hashes, `no_retuning=true`, and disjoint task, domain, and model cohorts. Matrix output is collision-gated, append-only, retains severe failures/exclusions/uncertainty in its analysis template, and includes a signature state of `HOLD_EXTERNAL_KEYLESS_SIGNATURE_REQUIRED` plus an exact fixture reproduction command. Its bundle timestamp is a timezone-aware frozen study value, so clean output roots produce byte-identical bundle files.

`scripts/run-protocol-v1-matrix.py --study <pack> --output <new-directory> --mode fixture` writes only a plan and template. It makes no provider or local-runtime request. `--mode confirmatory` fails closed until the checked-in preregistration has a real public immutable identifier and timestamp and every frozen binding is non-placeholder; even then this offline command reports admission readiness and does not start a provider.

Native Ollama and LM Studio admission have been exercised with bounded synthetic probes. Ollama completed the durable execution-to-receipt path; LM Studio produced a typed identity-evidence HOLD. Both are recorded in [local-runtime exploratory evidence v1](evidence/local-runtime-exploratory-v1.md); neither is a flagship or transfer matrix cell or can be retroactively promoted into preregistered evidence.

Remaining external HOLDs are: actual non-placeholder frozen policy bindings, public immutable preregistration publication, every frozen confirmatory matrix cell with source usage and cost reconciliation, an externally generated keyless signature bundle, human calibration where required, and independent reproduction. Integrity manifests prove custody only, not correctness, empirical performance, causality, transfer, cost, energy, or deployment.
