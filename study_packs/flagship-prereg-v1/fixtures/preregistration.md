# Flagship Protocol-v1 preregistration draft

Status: `HOLD_NOT_PUBLIC_IMMUTABLE`.

This repository artifact freezes the proposed flagship matrix only. It is not
publicly registered, does not authorize a provider request, and carries no
empirical result or causal claim. A public immutable identifier and timestamp
must be recorded before confirmatory dispatch can be admitted.

The frozen contract declares models, harnesses, local runtime identities,
evaluators, budgets, stopping rules, exclusions, severe-failure retention,
analysis, and multiplicity handling. Recorded fixtures are kept separate from
live evidence.
