# No-retuning transfer Protocol-v1 preregistration draft

Status: `HOLD_NOT_PUBLIC_IMMUTABLE`.

This repository artifact freezes selection and transfer design before any
confirmatory execution. The transfer cohort must remain disjoint from
selection tasks, domains, and models; its configuration hash must equal the
frozen selection configuration hash. No result may be used to tune either
configuration after selection freezes.

This draft is not a public preregistration and authorizes neither provider
requests nor empirical claims. Publication requires an external immutable
identifier and timestamp.
